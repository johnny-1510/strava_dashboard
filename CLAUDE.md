# Strava Dashboard

Eine einzelne `index.html` (HTML/CSS/JS, kein Build-Schritt).

## Code-Regeln
- So wenig Code wie möglich: die kleinste Änderung, die die Aufgabe vollständig löst.
- Keine neuen Abhängigkeiten, Abstraktionen oder Optionen, um die niemand gebeten hat.
- Erst vorhandenen Code und Browser-Bordmittel nutzen, bevor etwas Neues dazukommt.
- Löschen schlägt Hinzufügen.
